# Portfolio Generator

Fill in a form, preview your portfolio live, and download it as a single self-contained HTML file. Frontend only — no auth, no database.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run preview`, `npm run lint`.
